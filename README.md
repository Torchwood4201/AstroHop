# AstroHop
Retro 2D platformer (Phaser 3 + Vite) built as a sandbox to learn game development and probe the capabilities of the Claude Fable 5 model.   Mario-style platformer made from scratch — equal parts game-dev learning project and an experiment in building software alongside Claude Fable 5.
